📲 2. Tải theo nền tảng thiết bị

Sau khi vào trang chủ của server đã chọn ở bước 1, bạn sẽ thấy các nút tải game theo từng nền tảng. Dưới đây là hướng dẫn chung áp dụng cho cả 3 server:

Nền tảngPhù hợp vớiGhi chú
📱 AndroidĐiện thoại Android phổ thôngCài trực tiếp file APK từ trang chủ server
🍎 iOSiPhone / iPadCài qua chứng chỉ hoặc TestFlight theo hướng dẫn riêng
💻 PCMáy tính WindowsTrải nghiệm màn hình lớn, thao tác bàn phím/chuột
📟 Bản JarĐiện thoại "cùi", cấu hình yếuNhẹ, chạy mượt trên máy cấu hình thấp
💡 Nếu không chắc thiết bị của mình hợp với bản nào, hãy bắt đầu với bản Android (phổ biến nhất) hoặc liên hệ Trung tâm Hỗ trợ để được tư vấn.
⚠️ 3. Không tải / không vào được game?
Hãy mở liên kết tải bằng trình duyệt Chrome hoặc Safari — tránh bấm link ngay trong Zalo, Messenger hoặc Facebook vì các trình duyệt nội bộ này thường chặn tải file cài đặt.
Thử xoá dữ liệu ứng dụng (bấm nút "Xoá dữ liệu" ở màn hình đăng nhập lần đầu), kiểm tra lại bạn đã chọn đúng server đã đăng ký, và đảm bảo đang dùng Chrome/Safari nếu chơi qua web.
Thường xảy ra sau khi server vừa cập nhật dữ liệu mới. Vào game, bấm nút "Xoá dữ liệu" ở góc dưới bên phải màn hình để tải lại tài nguyên mới nhất.
Liên hệ ngay đội ngũ hỗ trợ qua Trung tâm Hỗ trợ kèm ảnh chụp màn hình lỗi, server đang chơi để được xử lý nhanh nhất.
