Giới Thiệu Thanh Di Studio

Thanh Di Studio là đơn vị phát triển và vận hành hệ thống server game Ngọc Rồng tại Việt Nam — nơi hội tụ TDStudio, NCD, Cindy và cộng đồng game thủ đông đảo.

Thanh Di Studio là ai?

Thanh Di Studio khởi đầu từ server Ngọc Rồng TDStudio — dự án private server Ngọc Rồng Online được phát triển từ năm 2023, trải qua hơn 3 năm vận hành liên tục với 6 server chính thức (Server 1 – Server 6) cùng một server dành riêng cho cộng đồng người chơi Indonesia. Từ nền tảng đó, Thanh Di Studio mở rộng thành một hệ sinh thái nhiều server với những trải nghiệm khác nhau, phục vụ đa dạng gu chơi của cộng đồng:

  • Ngọc Rồng TDStudio — server dame trung, sự kiện diễn ra liên tục, cộng đồng đông đảo, phù hợp người chơi thích cày cuốc vừa phải và tham gia sự kiện thường xuyên.
  • Ngọc Rồng NCD — server dame gốc, giữ nguyên trải nghiệm nguyên bản của Ngọc Rồng Online, đề cao tính công bằng và cân bằng giữa người chơi mới và người chơi lâu năm.
  • Ngọc Rồng Cindy — server mới nhất trong hệ thống, kế thừa nền tảng vận hành ổn định từ TDStudio và NCD.

Hành trình phát triển

Mỗi server mới trong hệ thống Thanh Di Studio đều được mở sau khi server trước đó đã chứng minh được sự ổn định lâu dài — ví dụ Server 6 của TDStudio chỉ được mở sau khi Server 5 hoạt động ổn định hơn 6 tháng. Cách tiếp cận "chậm mà chắc" này giúp Thanh Di Studio giữ được lượng người chơi trung thành qua nhiều năm, thay vì mở ồ ạt rồi bỏ server giữa chừng như nhiều server tự phát khác.

Hệ thống cũng áp dụng cơ chế liên server (cross-server) ở một số tính năng, giúp người chơi giữa các server trong hệ thống có thể giao lưu, thi đấu và kết nối với nhau.

Cam kết của Thanh Di Studio

  • Vận hành minh bạch: mỗi server đều trải qua giai đoạn Test → Đua Top Test → Reset dữ liệu → Đua Top Open → Chính thức, đảm bảo mọi người chơi đều xuất phát công bằng khi server chính thức mở cửa.
  • Bảo vệ người chơi: hệ thống được bảo vệ trước tấn công DDoS, có cảnh báo rõ ràng về tình trạng giả mạo admin để lừa đảo qua Zalo/Messenger — người chơi tuyệt đối không cung cấp mật khẩu cho bất kỳ ai.
  • Hỗ trợ tận tâm: đội ngũ hỗ trợ trực tuyến hằng ngày, phản hồi qua Zalo và Telegram, xem chi tiết tại trang Hỗ trợ.
  • Sự kiện liên tục: các dịp lễ Tết, Giáng sinh, sự kiện tương tác cộng đồng được tổ chức đều đặn với phần thưởng giá trị — xem tại trang Sự kiện.
