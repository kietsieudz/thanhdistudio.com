Set Kích Hoạt 7 Cấp Bậc

Từ Set Thường đến Set Vampa huyền thoại — lộ trình nâng cấp trang bị đầy đủ cho mọi giai đoạn của game.

7 cấp bậc từ thấp đến cao
  1. Set Thường
  2. Set Thần Linh
  3. Set Thiên Sứ
  4. Set Thần Tiên
  5. Set Hạ Tôn / Chí Tôn
  6. Set Vampa

1. Set Thường (Top 7)

Cấp thấp nhất, dễ tiếp cận nhất. Lấy được qua giftcode tân thủ hoặc đánh quái tại 3 bản đồ cạnh làng xuất phát.

2. Set Thần Linh (Top 6)

Lấy qua 2 cách: tham gia thí luyện cá nhân (gặp Giu-ma), hoặc tham gia Đại chiến Mabư diễn ra lúc 21h hằng ngày rồi đổi phần thưởng tại Santa.

3. Set Thiên Sứ (Top 5)

Cần một chuỗi đổi nhiều bước:

  1. Đổi trang bị Thần Linh → trang bị Thần Hủy Diệt
  2. Đổi trang bị Hủy Diệt → gặp Thiên Sứ Whis tại hành tinh Kaio
  3. Đổi tiếp sang trang bị Thiên Sứ
  4. Đến Bà Hạt Mít để nâng cấp kích hoạt hoàn chỉnh

4. Set Thần Tiên (Top 4)

Lấy bằng cách đổi phiếu giảm giá thu được từ việc đánh bại boss Doraemon, Liễu Thần hoặc quái tại đường hầm rắn độc — sau đó đổi tại Santa.

5. Set Hạ Tôn / Chí Tôn (Top 3 – Top 2)

Chế tạo tại Bà Hạt Mít kết hợp mua rương Chí Tôn tại Santa. Điểm đặc biệt: bạn có thể chọn loại set mong muốn, không bị random như nhiều hệ thống khác.

6. Set Vampa (Top 1 — huyền thoại)

Cấp cao nhất, có 2 con đường:

  • Con đường farm: đạt Set Thiên Tôn 12 sao → đến Vách Núi Đen gặp Paragus → mở khoá hành tinh Vampa → tiêu diệt Broly/Super Broly để có tỷ lệ rơi ngẫu nhiên trang bị Vampa (lưu ý: đồ rơi từ đây không thể giao dịch).
  • Con đường nạp thẻ: Top 1–2 bảng xếp hạng nạp thẻ hằng tháng nhận thẳng set Vampa đã kích hoạt tối đa.
💡 Không cần vội lên set cao ngay — hãy hoàn thiện set hiện tại trước khi chuyển cấp tiếp theo, tránh lãng phí tài nguyên nâng cấp dở dang.
